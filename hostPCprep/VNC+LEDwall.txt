In `~/.config/labwc/rc.xml`, make the `Super+V` binding create the virtual output and configure both outputs:

```xml
<keybind key="W-v">
  <action name="VirtualOutputAdd" output_name="VNC"/>
  <action name="Execute" command="sh -c 'sleep 1; wlr-randr --output VNC --pos 0,0 --custom-mode 768x768@60Hz; wlr-randr --output DP-4 --pos 0,0 --custom-mode 768x768@60Hz'"/>
</keybind>
```

Labwc documents this virtual-output action as a binding; its documentation also cautions that overlapping a virtual and physical output isn’t explicitly supported by wlroots. [1]

First reload and test the binding once:

```bash
labwc --reconfigure
ydotool key 125:1 47:1 47:0 125:0

```

```sh

```

Labwc runs its `autostart` file when the session starts. [2] The delay gives labwc and the user-level `ydotool` service time to start. Reboot and check `wlr-randr` again.

If your VNC server is wayvnc, make sure it captures the `VNC` output rather than `DP-4`; output selection is configured separately from creating the output. If you want VNC to show the **same physical display image** while the NovaStar is connected, wayvnc should capture `DP-4`, not `VNC`:

```bash
wayvnc --output DP-4
```

If instead you select `VNC`:

```bash
wayvnc --output VNC
```

wayvnc captures that virtual output. It’s a separate output, even though it belongs to the same labwc session; don’t assume it will be a pixel-for-pixel mirror of `DP-4`. wayvnc captures one output at a time, and `--output` selects which one. [1]

So the choice depends on what “same” means:

- **Same desktop session, virtual screen usable with or without HDMI:** capture `VNC`. Set both outputs to 768 × 768, but their displayed contents/layout may differ.
- **Exact image shown on the physical NovaStar:** capture `DP-4`. That won’t work when `DP-4` is disconnected; switch wayvnc to `VNC` for headless access.

You can check the available output names with:

```bash
wayvncctl output-list
```

and change the capture output without restarting wayvnc:

```bash
wayvncctl output-set output-name=VNC
# or
wayvncctl output-set output-name=DP-4
```

For an always-available connection, configure wayvnc to capture `VNC`; for a literal mirror of the NovaStar image, you’ll need a mirroring/clone feature in the compositor or video path. Labwc’s virtual output plus matching resolution alone doesn’t guarantee that. [1]
